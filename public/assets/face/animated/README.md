# Модульный атлас мимики — alpha animation review

Атлас состоит из трёх страниц WebP и `atlas.json`. Это самостоятельные глаза, брови и рты плюс анимация ключами; не покадровая сетка целых лиц. Настроенные sly/happy/grumpy используют прежнюю страницу `../study/three-expressions.webp` и точные пользовательские координаты без перерисовки.

Новые страницы: `expressions-nine.webp` (887×1774, разнесённые органы девяти выражений) и `eye-variants.webp` (1536×1024, сменные глаза испуга/удивления/оглушения, прямо/влево/вправо). Цветовые WebP с качеством 96, альфа с качеством 100. Части кадрируются UV-прямоугольниками из JSON; материал фильтрует альфа-края. Созданы встроенным ImageGen специально для проекта по согласованным пользовательским референсам. Не сторонние лицензионные ассеты. Черновые изображения с перекрывающимися органами в репозиторий не включены.

Последовательность подготовки: исходные девять выражений → уменьшение радужки/зрачка viewer-left глаза безумного выражения до приблизительно трети диаметра → отдельные органы на 3×9 сетке → отдельные глаза с малой радужкой и направлениями взгляда. Белки не уменьшались. Все стадии использовали встроенный imagegen, не CLI/API.

`clips`: длительности IN/HOLD/OUT и ключи browLift/eyeSquash/mouthPulse. Клип проигрывается один раз, удерживается и возвращается к выбранной базе; автопросмотр — отдельная функция проверочной страницы. BLINK 0.15+0.10+0.15 секунд; при полном закрытии радужки/зрачки скрыты. KO/dizzy не моргают.

`combo`: 3 оборота за 0.70 с, три полупрозрачных следа; затем 2.1 с dizziness со stop-флагом и 0.35 с восстановления. В превью stop-флаг останавливает вращение тела, сфера покачивается. Это проверка движения лица на сфере, НЕ уже подключённая физическая остановка в основной игре.

Всего 13 состояний: 12 эмоций, включая отдельное сознательное оглушение, плюс KO с крестиками. Рот KO ВРЕМЕННЫЙ: пользователь попросила позже дорисовать его корявой ломаной линией, вместо открытой пасти. Не объявлять текущий рот финальным.

Код: src/face/AnimatedAtlas.ts, AnimationClock.ts; просмотр: `?face-animations`. Основная игра пока использует три ранее принятых лица. Назначение новых эмоций событиям, физические последствия/пороги комбо и замена технических колец на ягоды — отдельные незавершённые задачи. main без SDK.
