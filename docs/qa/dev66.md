# dev.66 — весь рельеф долины

Пользователь попросила перейти от фрагментарного строительства к общей композиции всей карты. Выполнена первая цельная раскладка крупных высот на поле 400×400 м; художественная завершённость не заявляется.

145 Node-тестов PASS; TypeScript и production build PASS. Сохранён шаг земли/коллизии 2 м, новые высоты входят в тот же terrainData. Новых материалов, текстур и draw calls нет; девять дальних декоративных камней удалены. Верхняя граница физических стен поднята с 30 до 80 м, чтобы новый рельеф не позволял выкатиться поверх прежней стены.

Физически проходят все 11 прежних прогулочных направлений, основной маршрут с поездом, мосты и пляжные выходы. Новый тест проверяет реальные высоты крупных массивов, непрерывность по всему полю и конечность данных. Физический проезд всех новых склонов и настройка их сложности остаются открытыми.

См. VALLEY_MASTERPLAN.md: назначение зон и изменение подготовки теста сжатого поезда. Код поезда, вода и управление не менялись.

Промежуточный обзор карты был просмотрен в Chromium/SwiftShader, затем уточнялась граница защищённой центральной области. Итоговый browser smoke production build PASS: запуск, комбо и возврат лица, reset с seed 4321, четыре камеры, FOV52, 16:9 с полями; errors=[]; 68 draw calls, 1 103 314 треугольников в тестовом кадре. Общий обзор и игровой кадр просмотрены. Программный SwiftShader не подтверждает мобильный FPS. Android dev.66 не проверен; пользователь подтвердила предыдущую версию с неоднозначным номером «60-4», отметив художественную проблему гор.
