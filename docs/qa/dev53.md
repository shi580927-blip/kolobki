# dev.53 — объёмный водопад, 30.10.2026

Плоская падающая полоса и накладные ленты заменены шестью перекрывающимися замкнутыми изогнутыми струями. Один меш, 5328 треугольников, боковые поверхности и крышки; толщина не исчезает сбоку. Шейдер использует геометрические нормали, угловой блик, движущиеся полосы/пенные пятна и небольшое смещение поверхности. Движение сверху вниз сохранено. Верхний канал — прежний материал на отдельном коротком меше; озеро не менялось.

У основания 36 капель вместо 28, более высокий разлёт, 14 ограниченных мягких облачков взвеси; прежние пенные пятна/скопления сохранены. На первом игровом кадре капли выглядели тёмными: материал заменён светлым без зависимости от направления солнца, блики струй смягчены. Все частицы используют фиксированные InstancedMesh, без роста списка объектов. Отражения отдельным рендером, SSR, новые текстуры и симуляция жидкости не добавлены. По сравнению с dev.52 добавлен один пакет отрисовки для взвеси.

129/129 Node-тестов и production build прошли. Новый тест проверяет видимость объёмного потока лучами спереди, сзади и сбоку, нормали/конечные координаты и лимит 6000 треугольников. Сохранены прежние регрессии управления, лица, 16:9, маршрута, арки и моста с вагонами. Из-за неполных логов параллельного запуска полный локальный набор дополнительно выполнен последовательно (--test-concurrency=1), 129 прошли, 0 ошибок.

Игровой проход штатным джойстиком: старт → (-7,10) → (-7,27) → (-18,38) → (-22,32), затем обзор водопада штатной площадкой камеры. Chromium/SwiftShader, 1280×720, FOV52, без NPC; без телепортации или изменения игровой дистанции. Кадр dev53.png и видео dev53.mp4 сняты из игры.
