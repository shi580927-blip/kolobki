# Два слоя нормалей воды — рабочая ветка

По приоритету пользователя выполнен первый этап материала воды: периодическая normal map 128×128, генерируемая однократно, два UV-слоя с разными масштабами/скоростями/направлениями, нормализованная итоговая нормаль, угловой Fresnel, упрощённое отражение градиента неба, солнечный блик, прозрачность по реальной глубине, тонкая береговая кромка. Это не cubemap/SSR и не отражение всей сцены. Реальная глубина и плавучесть не менялись. Каустики на дне и новая физика плавания не добавлены.

После первого кадра ослаблены чрезмерные блики/сила нормалей. Текстура RGBA занимает 64 КиБ без mipmaps и около 85 КиБ с ними; два текстурных чтения, без отдельного рендера отражений. Стоимость на реальном телефоне не измерена.

Проверки: production build, 126 Node-тестов. Новый тест проверяет нормали, повторяемость, фильтрацию и ограниченный размер текстуры. Реальный проход штатным джойстиком и обзор в Chromium/SwiftShader, 1280×720/FOV52, без NPC. Конечная позиция (-20.48,2.90,31.74), wetness=1. В контрольном кадре основной рендер 55 calls / 625984 triangles. Ошибок консоли в проходе нет. Кадр и 20-секундное видео рядом с этим файлом; маркировка dev.51 означает рабочие изменения над этой версией.

Художественная приёмка, Android/iOS и аппаратный FPS впереди. Водопад остаётся отдельной незавершённой пробой. Ветка work/waterfall-study; опубликованная игра пока dev.51.
