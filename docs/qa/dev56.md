# dev.56 — скалы без игольчатых травинок

Удалён InstancedMesh из 112 тонких травинок на скалах/уступах плато. Зелёные верхушки сохранены в цветах каменного меша. Форма, нормали, цвета, материал, коллизии, вода и прочие механики не менялись.

Проверка геометрии: SHA-256 позиций/нормалей/color/stoneCoord всех частей скал до и после правки совпадает: 104c46896de49fc6ca9e0a562b489923235143d881e6a71f8c9183f568b60d1f. Каменные массы остаются одним мешем (608 треугольников), удалён только пакет растительности и его построение/привязка лучами.

130 Node-тестов и production build прошли. Игровой просмотр: Chromium/SwiftShader, 1280×720/FOV52, штатное движение джойстиком от старта к плато и обзор камерой без телепортации. Реальный кадр dev56.png рядом с отчётом. Ошибок console.error/pageerror нет; в финальном кадре 31 вызов основного рендера. Это не измерение аппаратного FPS.

Android/iOS, аппаратный FPS, полный матч и ручное комбо/reset в этой небольшой правке не проверены. Форма скал сохранена по просьбе пользователя; их дальнейшая художественная доводка не объявляется завершённой. Main не меняется, PR #3 остаётся Draft.
