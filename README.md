# Шаробесы — альфа 0.1

**main = чистый эталон без SDK, рекламы, платежей и IAP.** Разработка первого технического прототипа идёт в `feature/alpha-0.1`. В main переносить только проверенную и принятую сборку. Платформенные интеграции — позже в отдельных ветках по разрешению пользователя.

Текущая сборка `0.1.0-dev.28`: расширенный холмистый участок долины 220×220, маршрут около 262 м (раньше около 108), проход 12 м вместо 6. Новые широкие внешние холмы, более плавный вход на стартовую площадку, крупные уложенные по склонам стрелки и тройные перед поворотами. Следующая точка выделена золотым контуром/маяком. Это расширение игрового участка с прежним набором окружения, не окончательное художественное оформление всей локации.

Принятая пользователем основа dev.27: виртуальный джойстик увеличен, получил спокойную зону в центре и управление скоростью на земле. Отпускание мягко тормозит, смена направления убирает боковое скольжение; полёт и короткий импульс тарана сохраняются. Кнопка **«Джойстик: слева / справа»** сверху зеркально меняет джойстик, прыжок/таран и обзор; выбор сохраняется отдельно от seed. Клавиатура и NPC используют прежнюю модель. Настройка торможения пробная, нужна оценка на настоящем телефоне.

Основа dev.26: исправлено направление всех стрелок матча — теперь остриё смотрит к следующей точке маршрута. Остальная основа dev.25: заметный блок **«Начать матч»** с краткой целью и выбором свободного катания. После запуска — подсказка к жёлтой точке и расстояние. Сверху — **«Включить звук»** (с проверочным сигналом, затем выключатель) и **«Во весь экран»**. Звук повторно разблокируется после касания/возврата к игре; слышны прыжок, рывок, сбор и удары. Если браузер не разрешает fullscreen, появляется подсказка о запуске с главного экрана телефона. Добавлен manifest/standalone metadata; офлайн-режима нет. Реальные телефон/Safari/iOS и слышимость через динамик не подтверждены браузерной эмуляцией.

Основа матча dev.24: первая проба матча без подготовки на существующем участке долины. Кнопка **«Матч без подготовки»**: игрок и один NPC-лидер стартуют одиночными, четыре остальных NPC доступны для сбора в два независимых поезда. Маршрут виден на земле, следующая точка — жёлтая. Пройдите два круга через шесть точек по порядку; предел — 180 секунд симуляции. При равенстве точек по таймеру — ничья. Есть результат, повтор и возврат в песочницу («На старт» также выходит из матча).

В этой проверке матча **разрывы от контактов отключены**: оцениваются маршрут, сбор и удержание двух составов. В песочнице остаётся прежний пробный полный разрыв; он ещё требует пересмотра. Приёмка новой физики/боевого баланса не заявлена. Подготовленный старт, частичный разрыв, способности, выращивание, награды, новый мех и большая локация ещё впереди.

## Запуск

Node.js 22.12+ (проверено Node 24). `npm ci`, затем `npm run dev`. Для изолированной среды: `npm run dev -- --host 127.0.0.1`.

- `npm test` — тесты сохранения скина, состояний лица, геометрии, физических коллизий и независимости FaceRig.
- `npm run build` — TypeScript и production-сборка Vite в `dist/`.
- `npm run preview -- --host 127.0.0.1` — проверка production-сборки.

WASD / стрелки — движение относительно камеры; пробел — прыжок; Shift — таран; 1–4 — камеры; клавиша `~` — диагностика. На телефоне — джойстик, прыжок и таран. Одна логическая область 1280×720 (16:9), пропорциональный масштаб и поля на остальных экранах. Никаких responsive-перестроек и автоматического бега.

## Архитектура

`PlayerVisual` содержит соседние `rollingBody` и `FaceRig`. Вращение Rapier с интерполяцией применяется только к корпусу; FaceRig получает собственный курс по движению, сохраняемый в покое. Камера не поворачивает лицо к себе. Отдельные RGBA-глаза, брови и рот находятся на изогнутых поверхностях сферы. Моргание маскирует глаз сверху вниз без сжатия радужки; при закрытии видна только нейтральная линия на самом корпусе. Атлас v03 используется для визуальной приёмки альфы, художественная работа продолжается.

`FaceState` реализует постоянный baseMood, независимое моргание 0,4 с, IN/HOLD/OUT реакций и временный STUN. После реакции сохраняется базовый характер. Узоры процедурные и сохраняются через seed; редактора игрока нет.

`terrainData` — единый источник треугольников рендера и коллайдера. Rapier работает на фиксированных 60 Гц, графика интерполируется. `EventBus` — платформенно нейтральные события; `Effects` ограничивает число частиц. Snapshot создаёт локальный PNG без отправки на сервер.

## Браузерная проверка

После `npx playwright install chromium` запустите `npm run preview -- --host 127.0.0.1 --port 4173` и в другом терминале `npm run test:browser`. Тест сохраняет скриншоты, PNG-снимок и JSON в `test-results/`. Для собственного бинарника допустим `CHROMIUM_EXECUTABLE=/path/to/chromium`; это только тестовый параметр, не часть игры. Браузерная эмуляция не заменяет тест на устройстве.

В игре собираются 12 обычных ягод; «На старт» восстанавливает их и обнуляет счётчик. Старый ring-smoke относится только к историческому модулю колец. Текущая игровая проверка — `node scripts/alpha-world-smoke.cjs`.

Свободный ракурс на ПК: **зажать колёсико и двигать мышью**. В стороны — облёт, вверх/вниз — наклон; отпустить — сохранить выбранный ракурс. **1–4** или кнопка камеры возвращают стандартное следование. Браузерная проверка этого ввода: `node scripts/camera-smoke.cjs` при запущенном preview.

Проверка лиц в 3D: `?art-review` — 12 подписанных поз на разных скинах; `?art-review&blink=closed` — контроль закрытых глаз. Это read-only экран QA, без редактора, смены seed или выбора облика игроком. `node scripts/face-smoke.cjs` проверяет галерею и запуск игры при preview на порту 4191.

Контрастный тест лиц: `?art-review&lighting=shadow` — контровой свет. В dev.5 глаза/рты крупнее, детали цветные, у тела слабая подсветка для читаемости тёмной стороны. Seed и игровые параметры сохраняются.

По решению пользователя оставлен один мех — короткий кудрявый. Прямой покров исключён из автоматического назначения и авторского списка; старые JSON с `fuzz` принимаются и отображаются как `shaggy`, сохраняя seed, цвета и характер. Прежние пучки отложены, кудрявый материал не переработан.

Авторская ссылка `?valley-study` добавляет 10 разных образцов текущих скинов с живой мимикой. Они неподвижны, без AI, коллайдеров и сцепления: это проверка общего кадра, НЕ реализация NPC. Проверка: 63 Node-теста и production build PASS. Локальный Chromium с программным WebGL: десять образцов, сохранение seed, отсутствие образцов в обычной игре, 16:9 на широком окне — PASS без JS-ошибок. Игровой smoke: реальный сбор ягоды, остановка/восстановление комбо, камеры и сохранение seed — PASS. Реальный телефон, Safari/iOS и аппаратные 30+ FPS не проверены. Художественная оценка долины и общего кадра остаётся за пользователем.

Облака — отдельная следующая художественная задача по напоминанию пользователя. Текущие простые облака не считать готовыми или принятыми. Затем оценка участка и переход к настоящим NPC по существующему backlog.

Добавлен мягкий вертикальный цветовой переход неба и очень медленное ограниченное смещение облаков без появления/исчезновения по таймеру.
