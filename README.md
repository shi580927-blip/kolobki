# Шаробесы — альфа 0.1

**main = чистый эталон без SDK, рекламы, платежей и IAP.** Разработка первого технического прототипа идёт в `feature/alpha-0.1`. В main переносить только проверенную и принятую сборку. Платформенные интеграции — позже в отдельных ветках по разрешению пользователя.

## Запуск

Node.js 22.12+ (проверено Node 24). `npm ci`, затем `npm run dev`. Для изолированной среды: `npm run dev -- --host 127.0.0.1`.

- `npm test` — тесты сохранения скина, состояний лица, геометрии, физических коллизий и независимости FaceRig.
- `npm run build` — TypeScript и production-сборка Vite в `dist/`.
- `npm run preview -- --host 127.0.0.1` — проверка production-сборки.

WASD / стрелки — движение относительно камеры; пробел — прыжок; Shift — таран; 1–4 — камеры; клавиша `~` — диагностика. На телефоне — джойстик, прыжок и таран. Одна логическая область 1280×720 (16:9), пропорциональный масштаб и поля на остальных экранах. Никаких responsive-перестроек и автоматического бега.

## Архитектура

`PlayerVisual` содержит соседние `rollingBody` и `FaceRig`. Вращение Rapier с интерполяцией применяется только к корпусу; FaceRig получает собственный курс по движению, сохраняемый в покое. Камера не поворачивает лицо к себе. Отдельные RGBA-глаза, брови и рот находятся на изогнутых поверхностях сферы. Моргание маскирует глаз сверху вниз без сжатия радужки; при закрытии видна только нейтральная линия на самом корпусе. Атлас v03 используется для визуальной приёмки альфы, художественная работа продолжается.

`FaceState` реализует постоянный baseMood, независимое моргание 0,4 с, IN/HOLD/OUT реакций и временный STUN. После реакции сохраняется базовый характер. Узоры процедурные и сохраняются через seed; редактора игрока нет.

`terrainData` — единый источник треугольников рендера и коллайдера. Rapier работает на фиксированных 60 Гц, графика интерполируется. `EventBus` — платформенно нейтральные события; `Effects` ограничивает число частиц. Snapshot создаёт локальный PNG без отправки на сервер.

## Браузерная проверка

После `npx playwright install chromium` запустите `npm run preview -- --host 127.0.0.1 --port 4173` и в другом терминале `npm run test:browser`. Тест сохраняет скриншоты, PNG-снимок и JSON в `test-results/`. Для собственного бинарника допустим `CHROMIUM_EXECUTABLE=/path/to/chromium`; это только тестовый параметр, не часть игры. Браузерная эмуляция не заменяет тест на устройстве.

Кольца — тестовые собираемые предметы. Счётчик 0–12; «На старт» восстанавливает кольца и обнуляет счётчик. Дополнительная браузерная проверка: при запущенном preview выполните `node scripts/ring-smoke.cjs`.

Свободный ракурс на ПК: **зажать колёсико и двигать мышью**. В стороны — облёт, вверх/вниз — наклон; отпустить — сохранить выбранный ракурс. **1–4** или кнопка камеры возвращают стандартное следование. Браузерная проверка этого ввода: `node scripts/camera-smoke.cjs` при запущенном preview.

Проверка лиц в 3D: `?art-review` — 12 подписанных поз на разных скинах; `?art-review&blink=closed` — контроль закрытых глаз. Это read-only экран QA, без редактора, смены seed или выбора облика игроком. `node scripts/face-smoke.cjs` проверяет галерею и запуск игры при preview на порту 4191.

Контрастный тест лиц: `?art-review&lighting=shadow` — контровой свет. В dev.5 глаза/рты крупнее, детали цветные, у тела слабая подсветка для читаемости тёмной стороны. Seed и игровые параметры сохраняются.

[Открыть образец](https://shi580927-blip.github.io/kolobki/?skin-study) — однотонный корпус и 12 узоров, два цвета, масштаб/плотность/разброс, чешуя и сегменты, от одного до 240 наростов. Выбор мордочки, качение, свет/тень, уменьшенный игровой размер. Панель справа прокручивается: наросты и сохранение находятся ниже. JSON можно сохранить и прислать для воспроизведения варианта. Это авторский инструмент, основной SkinSeed не меняется. Детали и ограничения: [docs/SKIN_SYSTEM.md](docs/SKIN_SYSTEM.md).

Уточнение фактур 25.10.2026: чешуя и сегменты теперь отдельные объёмные ячейки с неодинаковой глубиной и наклоном части элементов. Они распределены по сфере без схождения к макушке. Пока эти два варианта однотонные: выбор фактуры снимает узор. Сочетаемость с рисунками согласуем позже.

Обновление подборки: в просмотре 15 узоров + однотон, включая переработанные тигровые полосы, зебру и жирафа; есть «Равномерный узор» и регулятор глянца для гладкого корпуса без наростов. Параметры сохраняются вместе с авторским вариантом.

## Камера dev.10
Справа отдельная область «КАМЕРА»: зажать и вести пальцем либо левой кнопкой мыши. Одновременно работает левый джойстик. После отпускания ракурс сохраняется; 1–4 / кнопка камеры возвращают пресет. Задняя камера плавно запаздывает по курсу, отдаляется при разгоне; FaceRig не меняет направления ради камеры.
Мех: основной цвет у корней, второй на кончиках. У наростов чекбокс второго цвета теперь окрашивает кончики.
[Подборка идей и границы реализации](docs/IDEAS_CAMERA_EMOTIONS.md). Художественное оформление всей долины ещё не завершено.

## Исправления dev.11
Мех и наросты освобождают место по текущему положению FaceRig, а не по прежнему «переду» сферы. Комбо сбрасывает вес прерванной эмоции и автоматически возвращает полностью видимую базовую мордочку. «На старт» очищает также физическую остановку комбо. Для повторной проверки густого меха двух типов: `node scripts/fur-combo-smoke.cjs` при запущенном preview; `CHROMIUM_EXECUTABLE` и `GAME_TEST_URL` при необходимости.
По решению пользователя в dev.11 оставлены только короткий мех и небольшие наросты. Ограничение применяется также к старым настройкам и максимальному разбросу; меняется размер деталей, а не идентичность скина. Чешуя/сегменты сохранены.

## Оглушение в воздухе — dev.12
Шар продолжает физический полёт под действием гравитации, пока управление заблокировано. Остановка и покачивание на месте происходят после контакта с опорой. Если оглушение закончится в воздухе, скорость сохраняется. Проверка: `node scripts/air-stun-smoke.cjs` при запущенном preview.

В dev.13 хитрая мордочка сжата по горизонтали на 10% и поднята целиком на 10% её прежней игровой высоты. Остальные эмоции сохранены.
