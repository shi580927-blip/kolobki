# Шаробесы / Sharobesy 🎮

Оригинальная браузерная 3D-аркада: живые шаробесы с характерными лицами катятся по широким холмистым локациям, собирают поезда и комично сталкиваются.

**Статус:** подготовка чистой альфы 0.1 к 7 ноября 2026 года. Полноценной играбельной сборки пока нет. Текущая ветка `feature/face-animations-v02` содержит только технический модуль управления эмоциями и тесты.

## Обязательные правила

- `main` — чистая независимая игра без SDK рекламы, IAP и платёжных библиотек; интеграции для Yandex / VK / OK / GamePush позже, строго в отдельных ветках.
- Первая мобильная версия: **горизонтально 16:9**, без адаптации на другие пропорции.
- Мордочка — отдельный слой поверх катящейся сферы, всегда смотрит в направлении движения (не в камеру). При сильном ударе может сорваться и вращаться, затем возвращается.
- Эмоции — **не бесконечный цикл**. Переход → короткое удержание → возврат. При моргании радужка/зрачок скрываются веками.
- Сильные столкновения должны сопровождаться **очень сочными** краткими спецэффектами.
- Никакого доступного игроку конструктора скинов в первый год; базовый облик назначается случайно и сохраняется.
- В коммерческой версии 1.0 — законченный матч против NPC с поездами и карточка эпичного события, которую можно сохранить и отправить.
- Видео/replay и настоящий PvP — поздние этапы.

## Технический первый модуль

- `src/face/FaceAnimationController.mjs` — независимый контроллер моргания, радости, ярости и оглушения.
- `docs/FACE_ANIMATION_SPEC.md` — требования к атласу и принципам проигрывания.
- `tests/FaceAnimationController.test.mjs` — тест конечных автоматов: `node tests/FaceAnimationController.test.mjs`.

Код контроллера готов к использованию с игровыми событиями. Художественные спрайт-атласы и полноценная 3D-игра пока не включены в репозиторий.
